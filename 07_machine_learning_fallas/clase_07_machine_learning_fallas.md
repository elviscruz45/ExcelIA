# Clase 07 — Machine Learning para Fallas

## Contexto industrial

El aprendizaje automático permite combinar múltiples variables de proceso para anticipar fallas antes de que crucen umbrales individuales.

## Conceptos clave

- **Clasificación binaria:** Normal vs. falla inminente.
- **Random Forest:** Ensemble robusto para datos tabulares industriales.
- **Importancia de features:** Identifica variables causales.

## Objetivos de aprendizaje

1. Construir dataset multivariable desde PI.
2. Entrenar y evaluar clasificador.
3. Interpretar matriz de confusión y curva ROC.

## Preguntas de reflexión

- ¿Qué riesgos tiene entrenar con datos desbalanceados en planta?
- ¿Cómo desplegarías el modelo como alerta en PI AF?
