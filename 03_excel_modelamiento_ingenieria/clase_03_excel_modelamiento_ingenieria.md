# Clase 03 — Excel y Modelamiento de Ingeniería

## Contexto industrial

Muchos equipos de ingeniería mantienen modelos de proceso en Excel (curvas de bomba, balances de masa). Integrar PI con Excel permite calibrar modelos con datos reales.

## Conceptos clave

- **KPI de eficiencia:** Relación entre medición y diseño.
- **Modelo híbrido:** Excel para parámetros, Python para cálculo masivo.
- **openpyxl:** Lectura/escritura de archivos `.xlsx`.

## Objetivos de aprendizaje

1. Leer parámetros de diseño desde Excel.
2. Calcular KPIs con datos PI.
3. Exportar resultados a `modelo_resultado.xlsx`.

## Preguntas de reflexión

- ¿Qué KPIs adicionales calcularías para una bomba centrífuga?
- ¿Cómo automatizarías la actualización diaria del modelo?
